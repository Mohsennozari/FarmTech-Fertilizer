## معرفی پروژه

**FarmTech** یک پلتفرم نرم‌افزاری حرفه‌ای برای مدیریت و محاسبه هوشمند ترکیبات کودی گیاهان در مراحل مختلف رشد است. این سیستم با استفاده از الگوریتم‌های بهینه‌سازی (حداقل مربعات) و دانش شیمی کشاورزی، بهترین دوز کودها را بر اساس:

- ✅ نیازهای تغذیه‌ای مرحله رشد (۱۳ عنصر اصلی)
- ✅ کودهای موجود در دیتابیس (انتخاب خودکار توسط سیستم)
- ✅ آنالیز آب مصرفی (EC، pH، کلسیم، منیزیم)
- ✅ تداخلات شیمیایی (هشدار رسوب و انسداد)
- ✅ فیلتر برند (شرکت تولیدکننده کود)

محاسبه و پیشنهاد می‌دهد.

## ویژگی‌های کلیدی

### 🧠 هوشمندی شیمیایی
| ویژگی | توضیح |
|-------|-------|
| **۱۳ عنصر اصلی** | N, P, K, Ca, Mg, S, Fe, Zn, Mn, Cu, B, Mo, Cl |
| **الگوریتم بهینه‌سازی** | حداقل مربعات (Least Squares) برای دوز چندین کود همزمان |
| **تداخلات شیمیایی** | بررسی خودکار و هشدار رسوبات خطرناک (کلسیم فسفات و ...) |
| **سهم آب و اسید** | کسر عناصر تامین شده توسط آب و اسید از نیاز گیاه |

### 🗄️ مدیریت دیتابیس
| ویژگی | توضیح |
|-------|-------|
| **Database Agnostic** | پشتیبانی از SQLite (توسعه) و PostgreSQL (تولید) |
| **JSON فیلدها** | ذخیره نیازهای تغذیه‌ای به صورت JSON برای انعطاف‌پذیری |
| **ارقام گیاهی** | پشتیبانی از ارقام مختلف (سن اندرسا، کاماروسا) |
| **تاریخچه محاسبات** | ذخیره خودکار تمام محاسبات برای مراجعه بعدی |

### 🎨 رابط کاربری
| ویژگی | توضیح |
|-------|-------|
| **REST API** | مستندات خودکار با Swagger UI و ReDoc |
| **طراحی حرفه‌ای** | Vue.js 3 + Tailwind CSS با تم روشن و مینیمال |
| **ریسپانسیو** | سازگاری کامل با موبایل، تبلت و دسکتاپ |
| **فونت فارسی** | پشتیبانی از Vazirmatn، Sahel، Samim، Yekan |
| **پرینت** | قابلیت چاپ نتایج با فرمت مناسب |

## نصب و راه‌اندازی

### راه‌اندازی بک‌اند

#### ویندوز (PowerShell)

```powershell
# 1. وارد پوشه backend شوید
cd C:\Users\Legion\Desktop\Karvarzi\Platform-v3\backend

# 2. ایجاد و فعالسازی محیط مجازی
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. نصب وابستگی‌ها
pip install -r requirements.txt

# 4. ایجاد فایل .env
echo DATABASE_URL=sqlite:///./farmtech.db > .env
echo DEBUG=True >> .env

# 5. پر کردن دیتابیس با داده‌های اولیه
python -c "from app.seed import init_db; init_db()"

# 6. اجرای سرور FastAPI
python run.py
----------------
