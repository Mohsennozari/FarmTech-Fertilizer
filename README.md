## معرفی پروژه

**FarmTech** یک پلتفرم نرم‌افزاری حرفه‌ای برای مدیریت و محاسبه هوشمند ترکیبات کودی گیاهان در مراحل مختلف رشد است. این سیستم با استفاده از الگوریتم‌های بهینه‌سازی (حداقل مربعات) و دانش شیمی کشاورزی، بهترین دوز کودها را بر اساس:

- نیازهای تغذیه‌ای مرحله رشد (۱۳ عنصر اصلی)
- کودهای موجود در انبار
- آنالیز آب مصرفی
- تداخلات شیمیایی
- فیلتر برند (شرکت تولیدکننده)

محاسبه و پیشنهاد می‌دهد.

---

## ویژگی‌های کلیدی

### 🧠 هوشمندی شیمیایی
- محاسبه دقیق ۱۳ عنصر اصلی (N, P, K, Ca, Mg, S, Fe, Zn, Mn, Cu, B, Mo, Cl)
- استفاده از الگوریتم کمترین مربعات (Least Squares) برای بهینه‌سازی همزمان دوز چندین کود
- بررسی خودکار تداخلات شیمیایی و هشدار در مورد رسوبات خطرناک
- در نظر گرفتن سهم عناصر تامین شده توسط آب و اسید

### 🗄️ مدیریت دیتابیس حرفه‌ای
- استفاده از SQLAlchemy ORM
- پشتیبانی از SQLite (توسعه) و PostgreSQL (تولید)
- ذخیره نیازهای تغذیه‌ای به صورت JSON برای انعطاف‌پذیری بالا
- ذخیره پارامترهای نظارتی EC و pH برای هر مرحله رشد
- پشتیبانی از ارقام مختلف گیاهی (سن اندرسا، کاماروسا)

### 🎨 رابط کاربری وب
- REST API استاندارد با مستندات خودکار (Swagger UI + ReDoc)
- رابط کاربری حرفه‌ای با Vue.js 3 و Tailwind CSS
- فرم چند مرحله‌ای با اعتبارسنجی
- نمایش جدول دوزهای دقیق (گرم بر لیتر، دوز مخزن، استوک ۲۰۰ برابر)
- نمایش هشدارهای ایمنی با کدگذاری رنگی (سبز/زرد/قرمز)
- نمایش مقایسه نیاز گیاه با تامین واقعی
- کاملاً Responsive و سازگار با موبایل
- پشتیبانی از فونت‌های فارسی (Vazirmatn, Sahel, Samim, Yekan)

## نصب و راه‌اندازی

### راه‌اندازی بک‌اند

#### ویندوز (PowerShell)

```powershell
# 1. وارد پوشه backend شوید
cd C:\Users\Legion\Desktop\Karvarzi\Platform-v3\backend

# 2. ایجاد و فعالسازی محیط مجازی
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. نصب وابستگی‌ها
pip install -r requirements.txt

# 4. ایجاد فایل .env (اختیاری - مقادیر پیش‌فرض کار می‌کنند)
echo DATABASE_URL=sqlite:///./farmtech.db > .env
echo DEBUG=True >> .env

# 5. پر کردن دیتابیس با داده‌های اولیه
python -c "from app.seed import init_db; init_db()"

# 6. اجرای سرور FastAPI
python run.py
====--------------====
